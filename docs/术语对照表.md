## 翻译约定

- **保护代币清单**（各语言保持不变，仅分隔符本地化）：SOL / USDT / USDC / PYUSD / USDS / EURC。
- **手续费数值**：每账户 0.0002 SOL（约租金 10%），链上手续费约 0.000005 SOL/签名。
- **累加器押金**：约 0.0018 SOL/账户。
- **「打狗」** 是中文圈黑话，按意思译「meme 币交易」，不按字面直译。
- **「貔貅币」** 统一用英语原词 honeypot（土）/ 허니팟（韩）/ ハニーポット（日），不用字面「蜜罐」译法（韩/日已音译，土耳其语已统一为 honeypot）。
- **「租金」** 用音译 렌트（韩）/ レント（日），不用「房租」类意译词（会误导）；韩语注意别与 보증금（押金）混用。
- 占位符 `{n}` `{total}` `{tx}` `{sol}` `{net}` `{fee}` `{count}` `{url}` `{i}` `{c}` 必须原样保留，不得翻译或增删。

## 待母语者核对

1. 土耳其语「sıfırlanmış coin」（归零币）也可考虑「sıfırlanan coin」，需确认哪种更自然。
2. 韩语「렌트」是否为圈内通用叫法，或更倾向「보증금」/「예치금」。
3. 日/韩语气是否与加密社区用语习惯一致（长句断句、敬语程度）。
