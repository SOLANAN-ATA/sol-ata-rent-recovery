Solana 退租金常见问题（FAQ）

关于退租金、关账户、手续费、安全的所有疑问，一次说清楚。

每个代币账户能退回多少 SOL？

约 0.00203928 SOL，这是 Solana 链上每个代币账户（ATA）的标准租金。打过的归零币越多，能退回的租金越多。

怎么查我的钱包锁了多少租金？

两种方式：① 把钱包地址发给 TG 机器人 @solata_rent_bot，秒回你锁了多少 SOL；② 打开 solata.top 连接钱包查看。

会不会误烧掉我值钱的币？

受保护代币 SOL / USDT / USDC / PYUSD / USDS / EURC 永不销毁。其余有余额的代币账户会被销毁并退回租金，所以赎回前请先自行转走钱包里有价值的币，避免误烧。

归零币、貔貅币这种有币的账户能退吗？

能，这是我们的核心优势。0 持币账户直接关闭退回；归零币、貔貅币这种有余额但卖不掉的账户，我们会先把代币烧掉，再关闭账户退回租金。市面上大多数工具只能退空账户，有币账户退不了——因为归零币、貔貅币卖不掉，账户清不了零。

我钱包里没有 SOL 了，还能退吗？

退回需要极少量 SOL 作链上手续费（约 0.000005 SOL/签名）。如果余额为 0，先充一点点 SOL 即可。

为什么有些账户显示「不可赎回」？

有些项目方给代币设置了 closeAuthority（关户权限），这种账户链上就关不掉。其余没有 closeAuthority 的账户都能退回租金。

平台收多少手续费？

每个账户收 0.0002 SOL，约租金（0.002 SOL）的 10%。退成功才收费，0 SOL 也能退。

安全吗？私钥会被拿走吗？

私钥永不离开你的钱包。全程只做「关闭代币账户 / 退回租金」的签名，不会转出你的 SOL、USDT 等资产。代码已在 GitHub 开源，欢迎审阅。

账户很多会怎么样？

账户较多时会自动分成多笔交易，每笔约 20 个账户，需要在钱包里连续确认几次签名。

什么是 Pump.fun 交易量押金（累加器）？

在 pump.fun 上打狗（交易 meme 币）时，pump.fun 会自动给你的钱包创建「交易量累加器」账户，锁定约 0.0018 SOL 押金，有的账户里还累积了返现（多的能有好几个 SOL）。它挂在 pump.fun 程序名下、不是普通代币账户，所以大多数工具扫不到。solata.top 能扫出来并全额退回（押金 + 返现，免手续费）。

为什么别的工具扫不到这笔押金？

因为绝大多数工具只扫 Token / Token-2022 两个程序的代币账户，而 Pump.fun 累加器挂在 pump.fun 自己的程序名下，属于第二类隐形资产。这是我们的技术护城河——专门逆向并支持了它。
