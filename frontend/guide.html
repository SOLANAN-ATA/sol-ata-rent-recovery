Solana 退租金教程：3 步拿回钱包里锁住的 SOL

你在 Solana 上每打一个归零币、垃圾币、貔貅币、空投币，钱包就自动开一个代币账户，锁住约 0.002 SOL 的租金。本教程教你一步步把它们全部拿回来。

💡 一句话原理
Solana 公链规定：每个代币账户（ATA）都要押一笔「租金」。账户能关掉，租金就退回；账户关不掉（币卖不掉、账户有余额），这笔 SOL 就卡在链上。我们帮你关掉这些僵尸账户。

第一步：地址查询 —— 先看你锁了多少、有哪些账户

不用连钱包，先在首页的 「🔍 地址查询」输入任意钱包地址（自己的、朋友的都行），系统会自动扫描并列出所有代币账户的具体明细：

  • 0 持币账户：账户里没有代币，可以直接关闭退回租金
  • 归零币账户：装着已经归零、卖不掉的垃圾币
  • 貔貅币账户：只能买不能卖的蜜罐币，账户被锁死
  • 受保护代币：SOL / USDT / USDC 等（系统不会碰）
  • 不可赎回：项目方锁了 closeAuthority 的账户（链上关不掉）

每个账户都会标出「可回收 SOL」，你一眼就能看清：锁了多少租金、哪些能退、哪些不能退。也可以用 TG 机器人 @solata_rent_bot 秒查。

第二步：连接钱包

1

切到「连接钱包退回」

在首页点「🔗 连接钱包退回」标签。
2

连接你的钱包

支持 Phantom / Solflare / OKX / TokenPocket / Backpack 等 Solana 钱包。注意：MetaMask 是以太坊钱包，不支持 Solana。

第三步：扫描并一键退回

点「扫描并一键退回」，系统会按第一步的明细自动处理：0 持币账户直接关闭、归零币和貔貅币先烧掉再关闭，然后在钱包弹窗里逐笔确认签名。每关一个账户，约 0.002 SOL 的租金就退回你钱包，平台只收 0.0002 SOL（约租金 10%）手续费，退成功才收费。

我们的优势：三类账户都能退

市面上大多数工具只能关「空账户」（0 持币）——账户里一旦还残留着代币余额，它们就退不了，因为你得先把币卖掉、账户清零。而归零币、貔貅币根本卖不掉，所以普通工具拿它们没办法。

我们能全覆盖：

  • ✅ 0 持币账户 → 直接关闭，租金退回
  • ✅ 归零币账户（有币但不值钱）→ 先把代币烧掉，再关闭账户，租金退回
  • ✅ 貔貅币账户（只能买不能卖）→ 先把代币烧掉，再关闭账户，租金退回
一句话：不管账户是空的、装着归零币、还是装着貔貅币，我们都能帮你烧掉、关掉、拿回租金。

额外彩蛋：Pump.fun 交易量押金（累加器）

如果你在 pump.fun 上打过狗（交易过 meme 币），pump.fun 会给你的钱包自动创建一个「交易量累加器」账户，同样锁定一笔约 0.0018 SOL 的押金。有些账户里还累积了返现，多的能有好几个 SOL。

这种账户挂在 pump.fun 程序名下，不是普通的代币账户，所以市面上绝大多数工具（只扫 Token / Token-2022）根本扫不到它——你的这笔押金就一直躺在链上。我们专门逆向并支持了它：

  • ✅ 扫描时自动显示：连接钱包后，累加器押金会和代币账户一起列出来
  • ✅ 一键退回：关闭累加器账户，押金 + 累积返现退回你钱包（扣 10% 手续费）
  • ✅ 收 10% 手续费：押金 + 返现退净额（扣 10%），和代币账户租金同费率
打狗的人几乎都有这笔隐形押金——别人扫不到，我们帮你退。
⚠️ 赎回前必看
系统会销毁所有「有余额」的代币账户（受保护代币除外）。赎回前请先自行转走钱包里值钱的币，避免误烧。受保护代币 SOL / USDT / USDC / PYUSD / USDS / EURC 永不销毁。
🔐 安全承诺
私钥永不离开你的钱包，全程只做「关闭代币账户 / 退回租金」签名，不会转出你的 SOL、USDT 等资产。代码已在 GitHub 开源。
